# Museum Mood launch

## Post

i thought i was making a reaction-image generator.

after many increasingly specific iterations, it became a tiny museum where you look people in old paintings directly in the eyes.

the first version was fast. figuring out what the thing actually wanted to become was the interesting part.

## Second reply

the first version looked like a conventional meme maker.

the current one came from repeatedly asking:

- can i get closer?
- can the motion feel physical?
- does this still feel like a museum?
- is the interface getting in the way of the face?

the code changed quickly. developing the taste to evaluate each version was the actual loop.

source: https://github.com/curiousjam/museum-mood
